
# Week 9 - Chatbot Development

## Project Title
Building an Interactive AI Chatbot using Ollama

## Objective
- Build an interactive chatbot using Python and Ollama.
- Accept user input continuously.
- Generate responses using a local Large Language Model (LLM).
- Maintain conversation history.
- Save conversations in a CSV file.

## Features
- Interactive command-line chatbot.
- Context-aware conversations.
- Conversation history storage.
- CSV-based chat records.

## Technologies Used
- Python
- Ollama
- Local Large Language Model (LLM)
- CSV files

## Project Structure
- dataset/
- notebook/
- chatbot.py
- README.md
- requirements.txt

## How to Run
1. Ensure Ollama is installed and a local model is available.
2. Install the required Python package.
3. Run the chatbot using:

   python chatbot.py

## Output
The chatbot accepts user messages and displays AI-generated responses in the terminal. Conversation records are saved for future reference.
